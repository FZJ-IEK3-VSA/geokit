# Explanation

The pages in this section explain why ETHOS.GeoKit works the way it does. They record design decisions and
the reasons behind them. For how to use a function, see the
[examples](../example_articles/_00_introduction.md) and the [API reference](../reference/index.md).

- [Data types](data_types/index.md): how GeoKit chooses the pixel type of a raster and the field type of a
  vector, recorded as architecture decisions.
