# Geodata Sources 

As obtaining data for geospatial analysis can be tedious, we have compiled a list of reliable sources to help you get started. Please note that it is your responsibility to check that the licences comply with your intended use.


# GADM 

Spatial data for countries and their subdivisions.

- https://gadm.org/

# Zenodo

Zenodo is primarily a repository for scientific data, but you can also filter by geospatial data.

- https://zenodo.org/

# GEBCO (General Bathymetric Chart of the Oceans)

Provides gloval Bathymetry data (elevation data). See https://en.wikipedia.org/wiki/Bathymetry for further information on Bathymetry.

- https://www.gebco.net/data-products/gridded-bathymetry-data
